# AI 内容项目展示

这两个个人项目面向小红书和公众号内容创作：一个帮助创作者收集资料、比较内容表现，为选题提供参考；另一个把素材整理、写作、人工审阅和发布前准备按步骤组织起来。

本仓库选取其中的部分代码，配有项目说明、演示数据和测试，不包含完整应用。

| 项目 | 解决什么问题 | 本次展示内容 | 技术栈 |
| --- | --- | --- | --- |
| [V2｜AI 内容创作系统](01_Content-Market-Research/README.md) | 收集小红书内容，整理分类和互动数据，帮助创作者研究选题方向 | 内容市场研究模块中的数据整理、分类结果检查、统计，以及 Mock API 与独立 MySQL 测试库联调 | TypeScript、React、MySQL |
| [V3｜AI 内容工作流](02_AI-Content-Workflow/README.md) | 按素材、初稿、定稿和公众号发布前准备推进工作，确保关键内容经过人工确认 | 阶段检查、稿件版本核对、精简工作说明和完整模拟交付样例 | Python；Skill 工作说明 |

[项目实现说明](docs/REVIEW_GUIDE.md)提供两个项目各一张业务架构与流程总览图，并标明本包展示环节；同时说明业务问题、设计原因和运行示例。两个项目目录提供对应代码、文件索引和运行命令。

## 先看新增模拟演示

- [V2 模拟联调](01_Content-Market-Research/examples/INTEGRATION.md)：本机请求、响应整理、测试库读写、模拟分类与统计。
- [V3 完整模拟交付](02_AI-Content-Workflow/examples/mock-delivery/README.md)：素材、初稿、检查记录、模拟确认、定稿和两张配图。下载后打开样例中的 preview.html 查看排版。

## 本展示包已完成哪些检查

34 项本地测试全部通过，其中 V2 为 10 项、V3 为 24 项；V2 的 6 个独立代码模块还通过了严格的 TypeScript 类型检查。

演示使用自行构造的数据，分类结果和确认状态也提前设定，新增 V2 联调实际连接本机 Mock API 与独立 MySQL 测试库，完成 5 条合成样本的读写和统计；没有调用真实外部服务、原业务数据库或 AI 模型。V3 新增从素材到正文配图的固定模拟交付及阶段回放。原完整页面和实际平台发布未验证。
