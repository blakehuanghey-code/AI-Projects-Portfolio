# 阶段与交接规则

以下规则按本包门禁代码整理。命令中的“下一步”指即将进入的阶段；脚本核对进入条件，不执行该阶段的内容制作。

| 下一步 | 进入条件 | 通过后由 Skill 与人工完成 |
| --- | --- | --- |
| `ai-draft` | 唯一素材包；素材确认与关键素材读取记录有效 | 形成母稿，提交正文审阅 |
| `final` | 上述条件；母稿确认、质量状态、非空依据与当前质量指纹有效 | 整理唯一终稿，记录与母稿的关联 |
| `wording-review` | 上述条件；当前母稿与终稿的关联匹配 | 准备标题、开头及指定渠道收尾，提交组合确认 |
| `platform-package` | 上述条件；文字组合确认与当前组合指纹匹配 | 制作指定平台包，检查后提交整包验收 |

## 版本关联

母稿指纹排除质量、关联与确认元数据，避免写入指纹后改变其自身。终稿关联同时记录母稿指纹和终稿文件 SHA-256；文字组合指纹由当前母稿指纹与终稿文件哈希共同生成。

只改确认记录日期不改变内容指纹。正文或选定文字变化后，需要复核受影响内容与对应确认，不能直接沿用旧指纹。

## 职责边界

写作 Skill 组织材料和正文，平台 Skill 接收唯一终稿并派生指定包；人工判断事实、表达和实际确认，脚本核对记录与版本。本包只演示到制包前检查，后续整包验收和发布未执行。

测试文件中的状态只用于验证脚本，不代表真实审批。素材包内容没有与母稿建立哈希关联，素材变更仍依赖人工复核。
