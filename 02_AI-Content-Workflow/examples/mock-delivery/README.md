## 回放阶段检查

在本模块根目录运行，Python 3.10 及以上，无需安装依赖：

```powershell
python -B examples/mock-delivery/replay-demo.py
```

脚本只在临时副本中切换模拟状态，调用本包已有检查函数，实际验证缺少确认、版本过期和图片引用等条件。不生成文章、不调用模型、不写原系统文件、不执行发布。

读者可以复现这套固定模拟交付的检查，不能用本包启动原业务系统。公众号后台的真实显示效果与发布尚未验证。
