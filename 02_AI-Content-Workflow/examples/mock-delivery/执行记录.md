# 模拟流程记录

本次按本包的两份精简 Skill 工作说明组织固定样例；不是原系统生产 Skill 的执行日志。稿件与模拟确认状态为预置夹具，脚本只回放检查，不自动写稿或审批。本版展示样式已获用户确认；不等于公众号实际发布授权。

| 阶段 | 工作说明 | 输入 | 输出或状态 |
| --- | --- | --- | --- |
| 素材准备 | content-writer 第 1 步 | 3 行合成数据与读者问题 | 素材包；缺确认时被实际脚本阻断 |
| 模拟素材确认 | content-writer 第 2 步 | 明确标注的模拟确认字段 | 进入初稿检查通过 |
| 初稿与审阅 | content-writer 第 3 步 | 素材包、预置初稿 | 质量检查、初稿修订说明；缺确认时阻断 |
| 模拟稿件确认与定稿 | content-writer 第 4 步 | 模拟母稿确认、质量记录 | 终稿与当前初稿的版本关联 |
| 文字组合确认 | content-writer 第 5 步 | 标题、开头、收尾 | 模拟确认记录与当前版本指纹 |
| 设计与排版 | wechat-package 第 1—4 步 | 已通过测试条件的终稿 | 本次独立设计的封面、信息图和 HTML 预览 |
| 整包交接 | wechat-package 第 5 步 | 公众号发布材料 | 展示样式已确认；未执行真实发布 |

实际脚本结果见 [replay-result.json](replay-result.json)。回放在临时副本上执行，先验证缺少确认会被阻断，再使用明确标注的模拟字段通过对应阶段，并检查改稿后旧指纹失效。原样例不会被改写。

本次设计与 HTML 是固定样例的独立产物，没有提供原项目的视觉模板、通用生成器、自动发布功能或模型提示词。
