# 从素材整理到终稿交接

这是本次新写的精简工作说明，配合仓库中的阶段检查脚本使用，不包含完整生产 Skill 的全部内容。以下命令均在 `02_AI-Content-Workflow` 目录执行。

1. 明确文章要回答的读者问题，以及可使用的材料和证据。整理唯一 `*_素材包.md`，分别记录素材确认状态和关键素材读取状态；尚未确认时只交付素材包。
2. 人工实际确认后，运行 `python -B scripts/check_stage_gate.py --article-dir <内容目录> --next ai-draft`。检查未通过时，先补齐对应材料或记录，不自行填写虚假的确认。
3. 形成 `*_AI初稿.md`，检查主要判断、例子和适用条件。记录母稿质量状态与具体依据，通过 `--fingerprint-draft <初稿路径>` 取得当前内容指纹，即稿件的版本标识。展示正文，等待人工确认。
4. 运行 `--next final` 并通过后，整理唯一 `*_最终发布稿.md`，通过 `--record-final` 记录终稿对应哪版初稿。该命令只写入关联字段，不代替人工确认。
5. 运行 `--next wording-review` 并通过后，根据定稿准备标题、开头和指定渠道的收尾，一起交人工确认。选定文字写入文件后，重新检查内容质量和稿件对应关系，再记录实际确认及 `--fingerprint-wording` 输出的版本标识。
6. 仅在 `--next platform-package` 通过后，交给 [wechat-package](../wechat-package/SKILL.md)准备公众号发布材料。正文变化后，重新检查受影响内容和对应确认，不沿用旧版本标识。

事实是否可靠、表达是否合适，必须由人工审阅；脚本不能替代这些判断。演示数据和提前设定的测试状态不得作为真实审批依据。
