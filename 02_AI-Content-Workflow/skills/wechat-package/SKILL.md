# 公众号制包交接

这是新写的展示说明，不与完整平台 Skill 等价。

1. 接收唯一终稿与当前文字组合记录，在 `02_AI-Content-Workflow` 运行 `python -B scripts/check_stage_gate.py --article-dir <内容目录> --next platform-package`。
2. 门禁通过后，仅为指定的公众号形态派生平台正文，保留已确认的标题、开头、例子、条件与收尾。
3. 把正文模块、配图用途和实际资产引用交给视觉检查环节。核对缺失文件、可读性、尺寸和隐私；本展示未提供视觉生成或完整检查器。
4. 可用 [引用解析函数](../../scripts/package_references.py)识别 Markdown/Obsidian 的本地图片引用。解析成功不代表文件存在或图片合格。
5. 完成内部检查后，整包交人工验收，状态保持待验收；未发生的平台实机核验和发布保持未验证。

本文件说明后续交接职责；展示包只提供制包前检查和图片引用解析，不生成实际平台包。
