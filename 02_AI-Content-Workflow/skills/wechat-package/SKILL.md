# 公众号发布材料准备与交接

这是本次新写的精简工作说明，不包含完整平台 Skill 的全部内容。

1. 接收唯一终稿，以及标题、开头和收尾的当前确认记录。在 `02_AI-Content-Workflow` 运行 `python -B scripts/check_stage_gate.py --article-dir <内容目录> --next platform-package`，核对是否可以开始准备发布材料。
2. 检查通过后，按指定的公众号内容形式整理平台正文，保留已确认的标题、开头、例子、适用条件和收尾。
3. 将正文各部分、配图用途和实际图片引用交给视觉检查环节，核对文件是否齐全、文字是否可读、尺寸是否符合要求，以及是否含有隐私信息。本展示包未提供视觉生成或完整检查工具。
4. 可用 [图片路径提取函数](../../scripts/package_references.py)找出 Markdown／Obsidian 正文中的本地图片路径。能提取路径，不代表图片文件存在或符合要求。
5. 内部检查完成后，将正文和配图作为一整套材料交人工验收，状态保持待验收。没有实际检查过的平台显示效果和没有执行过的发布，均记录为未验证。

本文件说明后续工作的交接方式；展示包只提供准备发布材料前的检查，以及图片路径提取，不生成实际平台发布材料。
